# ระบบจัดการคลังพัสดุด้วยไฟล์ไบนารี

โปรแกรมเทอร์มินัลสำหรับ Python 3.10+ ใช้เฉพาะ Python Standard Library และเก็บข้อมูลเป็นระเบียนความยาวคงที่ด้วย `struct` แบบ Little-Endian

## ไฟล์ข้อมูล

| ไฟล์ | Struct format | ขนาดต่อระเบียน |
|---|---|---:|
| `data/items.dat` | `<II64s24s12sIIfB3x` | 124 bytes |
| `data/categories.dat` | `<I64s80sB3x` | 152 bytes |
| `data/transactions.dat` | `<QIBIIf32s16sB3x` | 77 bytes |

สตริงทุกช่องเข้ารหัส UTF-8 ตัดที่ขอบเขตตัวอักษร และเติม `NUL` ให้ครบความยาว การลบเป็น Logical Delete (`status = 0`) และช่องที่ลบแล้วจะถูกนำกลับมาใช้ก่อนต่อท้ายไฟล์

## เริ่มใช้งาน

```bash
python3 main.py
```

สร้างไฟล์เปล่าและรายงานเริ่มต้นโดยไม่เปิดเมนู:

```bash
python3 main.py --init-only
```

เพิ่มข้อมูลตัวอย่าง 10 รายการจากภาพตัวอย่าง (ทำงานเฉพาะเมื่อไฟล์ข้อมูลว่าง):

```bash
python3 seed_sample.py
```

เลือกตำแหน่งไฟล์ข้อมูลและรายงานเอง:

```bash
python3 main.py --data-dir ./my_data --report ./my_report.txt
```

## เมนู

1. เพิ่มพัสดุ
2. แก้ไขพัสดุ
3. ลบพัสดุ
4. ดูรายการเดียว ดูทั้งหมด กรอง ดูพัสดุใกล้หมด สถิติ และประวัติ
5. สร้างรายงาน `.txt`
6. จัดการหมวดหมู่
7. รับพัสดุเข้า
8. เบิกพัสดุออก
0. สร้างรายงานอัตโนมัติและออก

## ทดสอบ

```bash
python3 -m unittest -v
```

ชุดทดสอบครอบคลุมขนาด struct, UTF-8 ภาษาไทย, CRUD, การใช้ช่อง Deleted ซ้ำ, ข้อมูลซ้ำ, การเบิกเกิน, referential integrity, ไฟล์เสีย และรายงาน
